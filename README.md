I'll keep adding examples, exercises, and small projects as I learn.

🧑‍💻 How to Practice

Make sure MySQL is installed on your system.

Open the MySQL client:

mysql -u root -p


Then select a database:

USE database_name;


Run SQL queries and experiment with different commands.
